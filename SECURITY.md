# Security Policy

Bridge is in early development. Do not use it to transfer sensitive information yet.

Report vulnerabilities privately through GitHub's private vulnerability reporting feature, if enabled, rather than publishing exploit details in an issue. Include affected commits, platform, impact, and reproducible steps. Never include credentials or private user data.

Security roadmap: mutual device approval, revocable identities, per-capability permissions, authenticated encrypted sessions, bounded message parsing, and no implicit cloud relay.
